FAIL Quotation amounts add up: net, untaxed, VAT and total

What happened
The test timed out waiting for the Save button. Line 1 already receives the VAT 18% tax automatically, so the "set tax" step changed nothing, the form was already saved, and there was no Save button to click. The quotation and its amounts were fine; the test did not allow for a form with nothing to save.
How to pass Fix applied
  1. The test code now treats "no Save button" as "already saved" (done in SalesPage.ts, trySave).
  2. Re-run: npx playwright test --project=setup --project=admin --grep "quotation amounts add up"
  3. Nothing needs to change in Odoo.

The sale (about 1.2 billion) is far above the credit limit. Request Credit Limit Approval and View Credit Limit Overdue Details appeared, Confirm stayed hidden, and after the request the approval showed "Waiting for approval".

SKIP Once the credit limit is approved the order can be confirmed

Odoo assigns the "Approve Credit Limit" task to Tharaka Herath. The signed-in user (Malsha Hewage) can only see "Waiting for approval", so this test skips itself.
How to pass

  3. Re-run the test. Note it confirms a real Sales Order on the live instance.

FAIL Blank Payment Terms / Salesperson / Sales Team / Company / Warehouse (05.4 – 05.8)

What happened
For these five tests Odoo accepted the save: the quotation received a number (for example S02047). So Odoo does not currently require these five fields to be filled. The test reported "no validation signal" because the Save icon reappeared after the save.
Important: the original specs showed PASS for 05.4–05.8 by mistake. They only checked the URL path, so a successful save was never noticed.
How to pass Fix applied to the test
  1. The test now detects a saved record correctly (the breadcrumb changes from "New" to the quotation number). After this change it fails with a clear message: "Odoo saved the quotation although <field> was blank."
  2. Decide per field whether it is meant to be required:
    1. If it must be required: make the field required in Odoo (Studio ▸ select the field ▸ Required), or add a rule that blocks saving. Re-run; the test then passes.
    2. If it is optional by design: remove that field from SALES_BLANK_FIELD_CASES in src/modules/sales/data/sales.validation-cases.ts. The test then no longer expects a block.
  3. Re-run Step 5: npx playwright test --project=setup --project=admin --grep "@step:validations"
